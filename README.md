# m5Dial
ESPHome + LVGL firmware for the M5Stack Dial (ESP32-S3) as a Home Assistant remote. Pages for clock, thermostats, RGBW/HWB lights, music players and NFC tags. Swipe left/right changes page, swipe up/down changes entity, the rotary knob adjusts values. Four view styles: Analog, 14-segment, Modern, Face.
